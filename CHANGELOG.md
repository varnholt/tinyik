# Changelog

## 0.1.0 — 2026-11-10

- Analytic two-bone IK with a pole point and minimum/maximum elbow bend.
- In-place FABRIK with optional interior-joint bend limits.
- Single-header C++23 implementation and dependency-free Rust crate.
- Caller-owned storage, input validation and explicit solve diagnostics.
- Shared WebGL 2 / OpenGL ES 3.0 giraffe playground driven by either compiled core.
- Native, cross-language and WebAssembly checks plus browser coverage.
